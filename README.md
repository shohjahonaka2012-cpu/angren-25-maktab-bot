# 🏫 Angren 25-maktab Telegram Bot

## 📌 Loyiha haqida
Ushbu loyiha Angren shahridagi 25-maktab o‘quvchilari uchun yaratilayotgan Telegram botdir.

## 🎯 Loyihaning maqsadi
Maktab haqidagi ma’lumotlarni, to‘garaklar faoliyatini va yangiliklarni o‘quvchilarga qulay tarzda yetkazish.

## 🚀 Asosiy imkoniyatlar
- 🏫 Maktab haqida ma’lumot
- 🎯 Maktab to‘garaklari ro‘yxati
- 📅 To‘garaklar mashg‘ulotlari jadvali
- 📝 To‘garaklarga yozilish uchun so‘rov yuborish
- 📢 Maktab yangiliklari va e’lonlari
- 🔐 Administrator uchun boshqaruv

## 🛠 Texnologiyalar
- Python
- Telegram Bot API
- python-telegram-bot
- GitHub

## 🔒 Xavfsizlik
Bot tokeni va boshqa maxfiy ma’lumotlar maxsus environment variables orqali saqlanadi.
Maxfiy tokenlar GitHub repository'ga joylashtirilmaydi.

## 📍 Loyiha
Angren shahri, 25-maktab.
